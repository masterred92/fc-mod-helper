# Live Editor scripts

The academy exporter lives at [`src/fcmh/lua/fcmh_academy_export.lua`](../src/fcmh/lua/fcmh_academy_export.lua)
so it ships inside the app. The **My academy** button copies it into your Live Editor's `lua`
folder for you. **Untested in-game.** See [../docs/academy-tracker.md](../docs/academy-tracker.md).

These scripts are for the PC Live Editor by xAranaktu (Lua API v2, Lua 5.4), which you get from
its official source. This repo does not include or redistribute Live Editor.
Offline Career Mode only.
